# Техническое задание: GameDealFinder

## Идея проекта
Агрегатор скидок на игры из различных платформ с отслеживанием исторического минимума цен.

## Цели
Создание веб-сервиса для мониторинга цен на игры. Система позволяет пользователям просматривать актуальные цены на игры, отслеживать исторические минимумы и получать уведомления, когда цена достигает заданного пользователем уровня. Сервис помогает пользователям экономить при покупке игр, агрегируя данные с различных игровых платформ

## Роли пользователей
1. Гость - просмотр игр, поиск нужной ему игры в общем списке
2. Авторизованный пользователь - создание списка ожидания, подписка на уведомления
3. Администратор - управление играми, магазинами, обновление цен

## Основные сценарии
1. Каталог и поиск
    * Гость или пользователь может просматривать все игры, фильтровать по названию, видеть актуальные цены и исторические минимумы
2. Отслеживание желаемых цен
    * Гость или пользователь может просматривать все игры, фильтровать по названию, видеть актуальные цены и исторические минимумы
3. Уведомления
    * Система отправляет email-письмо пользователю, когда цена игры становится равной или ниже желаемой
4. Синхронизация цен
    * Администратор или скрипт обновляет цены игр с внешнего API (ITAD), сохраняет историю цен и отмечает исторические минимумы
5. Просмотр деталей игры
    * Пользователь может открыть страницу игры и видеть: подробную информацию, текущие цены по магазинам, исторический минимум и возможность добавления в Waitlist

## Схема данных

### Модель 1: Game (Игра)
- title: Название игры
- itad_plain: Уникальные теги игры
- itad_id: ID игры в ITAD API
- release_date: Дата выхода
- developer: Разработчик
- publisher: Издатель
- lowest_price: Исторический минимум цены
- lowerst_price_currency: Валюта исторического минимума цены
- genres: Жанры игры
- image_url: Обложка

### Модель 2: Store (Магазин)
- itad_id: ID магазина в ITAD API
- name: Название магазина: (пример: Steam, Epic, GOG)
- website: Сайт магазина
- is_active: Активен ли магазин

### Модель 3: PriceHistory (История цен)
- game: ForeignKey к Game
- store: ForeignKey к Store
- price: Текущая цена
- discount_price: Цена со скидкой
- discount_percent: Процент скидки
- currency: Валюта
- recorded_at: Время записи
- is_history_low: Является ли цена историческим минимумом
- store_url: Сайт магазина

### Модель 4: Waitlist (Список желаемого)
- user: ForeignKey к User
- game: ForeignKey к Game
- targe_price: Желаемая цена
- created_at: Дата создания
- is_notified: Был ли уведомлен пользователь
- notified_at: Если был уведомлен, то в какую дату

### Модель 5: User (Пользователь)
- email: Почтовый адрес пользователя

## Внешние интеграции
