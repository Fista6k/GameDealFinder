# Техническое задание: GameDealFinder

## Идея проекта
Агрегатор скидок на игры из различных платформ (Steam, Epic Games, GOG) 
с отслеживанием исторического минимума цен.

## Цели
Создание агрегатора скидок на игры с различных платформ (steam, epic, gog) с отслеживанием исторического минимума цен.
Данная система помогает клиентам увидеть более выгодное предложение на данный момент, визуализируя динамику цен.

## Роли пользователей
1. Гость - просмотр игр, фильтрация, сортировка, просмотр графиков цен
2. Авторизованный пользователь - создание списка желаемого, подписка на уведомления, сохранение фильтров
3. Администратор - управление играми, магазинами, обновление цен

## Основные сценарии
1. Пользователь ищет игру и видит текущие цены во всех магазинах
2. Система показывает исторический минимум цены для каждой игры
3. Пользователь может подписаться на уведомление при достижении заданной цены
4. Администратор добавляет новые игры и магазины через админку
5. Автоматическое обновление цен через API внешних сервисов

## Схема данных

### Модель 1: Game (Игра)
- title: Название игры
- description: Описание
- release_date: Дата выхода
- developer: Разработчик
- publisher: Издатель
- genres: 
- platforms: 
- image_url: Обложка

### Модель 2: Store (Магазин)
- name: Название магазина: Steam, Epic, GOG
- website: Сайт
- api_endpoint: API для получения цен
- is_active: Активен ли магазин

### Модель 3: PriceHistory (История цен)
- game: ForeignKey к Game
- store: ForeignKey к Store
- price: Текущая цена
- discount_price: Цена со скидкой
- discount_percent: Процент скидки
- currency: Валюта
- recorded_at: Время записи
- is_lowest: Исторический минимум

### Модель 4: UserWishlist (Список желаемого)
- user: ForeignKey к User
- game: ForeignKey к Game
- desired_price: Желаемая цена
- notify_when_reached: Уведомлять при достижении

### Модель 5: PriceAlert (Уведомление)
- user: ForeignKey к User
- game: ForeignKey к Game
- target_price: Целевая цена
- created_at: 
- is_active:
